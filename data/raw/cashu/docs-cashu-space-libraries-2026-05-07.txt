## Libraries Cashu libraries allow developers to build wallets, mints, and other services that use Cashu. 

## [Python](/libraries#python) 
- [Cashu](https://github.com/cashubtc/cashu) Nutshell is a Python library for using Cashu wallets and mints inside other Python projects 
- [cdk-python](https://github.com/cashubtc/cdk-python) Python language bindings for the Cashu Development Kit (CDK) 

## [TypeScript & JavaScript](/libraries#type-script-and-java-script) 
- [Cashu-TS](https://github.com/cashubtc/cashu-ts) A TypeScript library for building Cashu wallets 
- [Coco](https://github.com/cashubtc/coco) A modular, TypeScript-first toolkit for building Cashu wallets and applications 
- [cashu-crypto-ts](https://github.com/cashubtc/cashu-crypto-ts) A TypeScript library that implements the basic cryptographic blinded signature scheme. 

## [Rust](/libraries#rust) 
- [cdk](https://github.com/cashubtc/cdk) wallet and mint library 

## [Kotlin](/libraries#kotlin) 
- [cdk-kotlin](https://github.com/cashubtc/cdk-kotlin) Kotlin bindings for the Cashu Development Kit (CDK) 

## [Swift](/libraries#swift) 
- [cdk-swift](https://github.com/cashubtc/cdk-swift) Swift bindings for the Cashu Development Kit (CDK) 
- [CashuSwift](https://github.com/zeugmaster/CashuSwift) Native Swift library for Cashu 

## [Java](/libraries#java)
