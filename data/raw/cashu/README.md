# data/raw/cashu/

Provenance snapshots from the Cashu ecosystem (docs + awesome list).

Files:
- `awesome-cashu-<YYYY-MM-DD>.md` — verbatim copy of [github.com/cashubtc/awesome-cashu](https://github.com/cashubtc/awesome-cashu)'s README at ingestion time.
- `docs-cashu-space-<page>-<YYYY-MM-DD>.txt` — extracted text content from docs.cashu.space pages.

These are kept so every wiki claim sourced from cashu.space / docs.cashu.space / awesome-cashu can be traced back to the snapshot it was synthesized from.
