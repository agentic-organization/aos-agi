# mintd (CDK mint)

**Status:** active · **Ecosystem:** [[projects/cashu]] · **Owner team:** [[teams/cashu-core]]
**Language:** Rust · **Kind:** mint (Rust)

## Summary
Rust mint implementation built on the [[projects/cdk]] library. Lives in the CDK monorepo at `crates/cdk-mintd` and is the recommended deployment target for new Cashu mints. Pairs with the CDK's wallet crates so the same codebase covers both sides of the protocol.
