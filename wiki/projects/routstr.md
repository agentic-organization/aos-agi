# routstr

**Status:** active · **Ecosystem:** [[projects/cashu]] · **Owner:** external (see below)
**Kind:** application (LLM marketplace)

## Summary
A **marketplace for buying and selling LLM API access** using Cashu ecash. Consumers pay per-request in sats; providers accept Cashu tokens. One of the clearest demonstrations of ecash as a programmable, account-free payment rail for machine-to-machine commerce.
