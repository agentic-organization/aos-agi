# Cashu.me

**Status:** active · **Ecosystem:** [[projects/cashu]] · **Owner team:** [[teams/cashu-core]]
**Language:** TypeScript / Vue.js · **Kind:** wallet (web)

## Summary
The reference Cashu web wallet and the most widely deployed consumer entry point into the ecosystem. Built on Quasar and Vue.js (TypeScript/JavaScript). Maintained by [[people/callebtc]] — the active source is [github.com/callebtc/cashu.me](https://github.com/callebtc/cashu.me) although the project is mirrored/hosted under the cashubtc org for continuity.
