# Nutsack

**Status:** active · **Ecosystem:** [[projects/cashu]] · **Owner:** external (see below)
**Kind:** wallet + library (Nostr NIP-60)

## Summary
NIP-60 Cashu wallet framework maintained by `pablof7z`. Several major Nostr clients embed Nutsack for their in-app wallets — notably [Olas](https://github.com/pablof7z/olas) (Instagram-like Nostr client). Because pablof7z is a prolific Nostr-ecosystem contributor, Nutsack acts as a de-facto reference for how NIP-60 Cashu wallets should be structured.
