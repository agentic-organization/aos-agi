# Proxnut

**Status:** active · **Ecosystem:** [[projects/cashu]] · **Owner:** external (see below)
**Kind:** application (ecash paywall proxy)

## Summary
Reverse proxy that **forwards HTTP requests only if they carry a valid Cashu token in the X-Cashu header**. A practical implementation of ecash-gated API access on top of the x-cashu pattern.
