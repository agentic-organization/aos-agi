# x-cashu

**Status:** draft / experimental · **Ecosystem:** [[projects/cashu]] · **Owner:** external (see below)
**Kind:** protocol (HTTP 402)

## Summary
Work-in-progress scheme that **delivers Cashu tokens in HTTP headers** to monetize REST API access — essentially reviving the HTTP 402 'Payment Required' status code via ecash. Maintained by [[people/callebtc]]; formalized under NUT-24 in the NUTs specs.

- GitHub: [callebtc/xcashu](https://github.com/callebtc/xcashu)
