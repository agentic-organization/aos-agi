# cocod

**Status:** active · **Ecosystem:** [[projects/cashu]] · **Owner:** external (see below)
**Language:** TypeScript (Bun) · **Kind:** wallet (CLI + daemon)

## Summary
Cashu wallet CLI **and daemon** built with Bun and TypeScript, using [[projects/coco]] as its library. Lets a single host run a background wallet process that other tools can talk to, rather than embedding Cashu inside each app.
