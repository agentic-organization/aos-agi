# ngit

**Status:** active · **Hub:** [[teams/foundry]] · **Organization:** [[teams/and-other-stuff]]

## Summary
A decentralized GitHub alternative built on Nostr for code collaboration. ngit enables issue tracking, pull requests, and repository discovery via Nostr relays, with git servers handling data storage and multiple backends for redundancy.
