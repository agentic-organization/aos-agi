# Wally

**Status:** active · **Ecosystem:** [[projects/cashu]] · **Owner:** external (see below)
**Kind:** application (TollGate client)

## Summary
Companion application for [[projects/tollgate]] — detects TollGate-equipped routers nearby and (auto)connects to them. Implements **Cashu Wallet Connect (CWC)**, an extension of Nostr NIP-47 (Nostr Wallet Connect) for applications interacting with Cashu wallets over Nostr.
