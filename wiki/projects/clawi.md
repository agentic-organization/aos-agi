# Clawi

**Status:** active · **Hub:** [[teams/foundry]] · **Organization:** [[teams/and-other-stuff]]

## Summary
Clawi (clawi.ai) is a managed cloud platform for personal AI agents. It hosts an agent continuously in the cloud so it can message the user, do research, and manage their life — reachable through WhatsApp, Telegram, Discord, Slack, Signal, iMessage, and other messengers. AOS takes care of infrastructure, security, and reliability so users focus on getting things done.

Clawi offers a choice of two open-source agent engines:

- **[[projects/openclaw]]** — community-powered.
- **[[projects/hermes]]** — self-improving.

And supports Anthropic Claude, OpenAI ChatGPT, and Google Gemini as backing models.

## Key capabilities (from clawi.ai)
- **Command Center** — real-time visibility into token usage, active contexts, active skills, model parameters.
- **Any Messenger** — WhatsApp, Telegram, Discord, Slack, Signal, iMessage.
- **Agent Email** — every agent gets its own inbox automatically.
- **Persistent Memory** — preferences, context, and past conversations remembered across sessions.
- **System Access** — full Linux environment with persistent storage; install packages, run services.
- **Teams** — share agents across an organization.
- **Privacy First** — no conversation logging.

## Plans (as of page creation)
