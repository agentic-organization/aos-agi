# BTCNutServer

**Status:** active · **Ecosystem:** [[projects/cashu]] · **Owner:** external (see below)
**Kind:** application (payment gateway)

## Summary
A **BTCPay Server plugin** that enables BTCPay instances to accept Bitcoin payments delivered as Cashu tokens. Bridges the self-hosted-merchant world (BTCPay) with the ecash world.
