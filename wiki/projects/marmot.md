# Marmot

**Status:** active · **Team:** [[teams/marmot-protocol]] · **Hub:** [[teams/foundry]] · **Organization:** [[teams/and-other-stuff]]

## Summary
The Marmot Protocol specifies how to do efficient end-to-end encrypted group messaging using Nostr's decentralized identity and relay network combined with the MLS (Messaging Layer Security) protocol. Marmot protects both content and metadata without requiring phone numbers or email addresses.
