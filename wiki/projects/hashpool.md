# hashpool

**Status:** active · **Ecosystem:** [[projects/cashu]] · **Owner:** external (see below)
**Kind:** application (mining pool)

## Summary
An **accountless Bitcoin mining pool** that uses ecash tokens to represent mining shares. Miners submit shares and receive Cashu tokens in return — no account, no KYC, no withdrawal approvals. A novel application of ecash as a unit of account for mining work.
