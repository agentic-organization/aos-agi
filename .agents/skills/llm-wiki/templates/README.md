# Templates

Skeleton files the `llm-wiki` skill copies from when creating new wiki pages. Keep these **minimal** — they're starting points, not prescriptions.

Current templates:

- [`person.md`](person.md) — `wiki/people/<slug>.md` starter
- [`skill.md`](skill.md) — `wiki/skills/<slug>.md` starter
- [`stub.md`](stub.md) — universal stub format for any page type

Edit these as page conventions solidify.
